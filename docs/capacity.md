# 容量与免费额度

## 本次优化

讨论使用每个 Community 独立的 WebSocket 通知通道，支持 Hibernation。没有变化时不再每两秒下载整页数据；连接正常时约每分钟核对一次。写入成功立即更新本人页面，其他成员收到合并通知后自动读取；刷新稍微错开并限制并行，隐藏页面暂停，断线后回退到轮询并在错误时延长间隔。

每次读取仍重新核对会话、成员和可见性。ETag 绑定当前身份、社区版本与辩题，无变化返回 304。快照只缓存已完成的普通数据，最多 24 项、约 8 MiB、60 秒，向客户端返回前逐人脱敏。人数、审核数、正反票和有效评论数由数据库触发器在写事务中维护，避免反复扫描历史记录。

共享校园出口的账号限流调整为每 IP 每分钟 300 次，用户名每分钟 15 次的限制继续保留。普通已登录操作按用户限流。密码保持既有 scrypt 参数，并限制同时计算数量，避免集中注册时大量分配内存。

## 本地验证结果

2026-10-17，Windows、Node 24、本地 workerd/Miniflare、D1 SQLite，使用最终构建和独立的测试社群：

| 场景                             | 结果           | 请求耗时 P95 |
| -------------------------------- | -------------- | ------------ |
| 100 人同时使用同一邀请加入       | 通过           | 2.46 秒      |
| 100 人同时首次读取               | 通过           | 0.48 秒      |
| 100 个实时订阅及通知后的自动读取 | 通过           | —            |
| 100 人同时投票                   | 通过，计数准确 | 1.76 秒      |
| 100 人同时发言                   | 通过，计数准确 | 2.42 秒      |
| 100 人读取已有讨论               | 通过           | 0.51 秒      |
| 100 次内容未变的条件读取         | 通过，无正文   | 0.40 秒      |
| 同一 IP 50 人同时注册            | 通过           | 7.94 秒      |
| 同一 IP 50 人同时登录            | 通过           | 7.69 秒      |

完整场景共 1,116 次 HTTP 请求，包含收到通知后的 300 次自动读取，14 项断言通过，没有请求失败。验证覆盖匿名脱敏、个人所有权、社区通知隔离、私密握手、成员移出后访问失效，以及评论移除后的缓存与计数更新。详细报告保存在忽略的 `app/test-results/capacity.json`。

曾尝试更高的 200 人混合负载，但 Windows 本地运行时出现原生 `WSASend` / `std::terminate` 崩溃和开发代理重启，因此没有把 200 人视为稳定通过。单独连接成功、单独写入通过都不足以证明完整场景稳定。

以上是本地测试，不代表公网延迟、Cloudflare CPU 限制或每日免费额度的保证。站点目前仍全量读取选中辩题的评论，特别长的讨论应继续增加分页或增量同步。

公网最终验收通过 39 次请求：Pages WebSocket 转发及真实通知送达、私密握手授权、ETag 失效与 Cloudflare 压缩后的弱标记比较、匿名和管理权限均正常。所有线上统计计数与实际记录一致，临时社区和虚构账号已清理。公网验收使用少量隔离请求，没有对真实训练社区进行压力测试。

## 复测

先在 `app/` 运行 `pnpm db:local`、`pnpm build`，停止其他使用同一本地数据库的预览服务，然后运行 `pnpm benchmark:start`。它只监听 `127.0.0.1:5185`，直接运行构建产物，避免开发代理自动重载影响结果。

在另一个 PowerShell 终端执行：

```powershell
$env:TEST_ORIGIN = "http://127.0.0.1:5185"
pnpm test:capacity
```

默认 100 个客户端，可用 `TEST_CLIENTS` 设置 2–250。脚本拒绝公网目标，只创建本地虚构用户与测试社区，结束时正常关闭 WebSocket。停止服务后再构建或迁移数据库。

## 免费额度估算

50 名成员在没有新动态、连接正常时，一小时约 3,000 次定时状态校验；之前每两秒轮询约 90,000 次。首次打开、WebSocket 握手、写入和收到变化后的读取另计，活跃讨论的请求量更高。不能将空闲请求减少约 97% 理解为承载人数增加 30 倍。

免费额度仍以 [Workers](https://developers.cloudflare.com/workers/platform/limits/)、[D1](https://developers.cloudflare.com/d1/platform/pricing/) 和 [Durable Objects](https://developers.cloudflare.com/durable-objects/platform/pricing/) 的官方规则为准；此次使用支持免费方案的 SQLite Durable Objects，没有开通付费套餐。
